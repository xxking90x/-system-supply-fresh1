# وثيقة المتطلبات (SRS) ومخططات النظام

## 1. وصف مسار العمل (Workflow)
- استلام الشحنة: يبدأ النظام بتسجيل منتج جديد (مثل الخضراوات) برقم تتبع (SKU) محدد، وإدخال بياناته مثل الكمية وتاريخ الصلاحية والحد الأقصى لدرجة الحرارة المسموح بها.
- فحص الحرارة: يتم مراقبة درجة حرارة الشحنة أثناء نقلها وتخزينها. يقوم النظام بعمل فحص مستمر (Audit).
- التلف التلقائي: إذا تجاوزت القراءة الحالية لدرجة الحرارة الحد الأقصى المسموح به للمنتج، يقوم النظام فوراً بإصدار تحذير (ALERT) وتغيير حالة الشحنة تلقائياً إلى "تالفة" (DAMAGED).
- التوزيع: في حال كانت جميع القراءات مطابقة للمعايير، تصل الشحنة إلى وجهتها بحالة سليمة ويتم تحديث المخزون.

## 2. مخطط حالات الاستخدام (Use Case Diagram)
كيفية رسمه في draw.io:
1. أضف "مستخدم" (Actor) وسمّه "موظف المستودع / Worker".
2. أضف "مستخدم" آخر وسمّه "النظام التلقائي / System".
3. أضف العمليات التالية داخل مربع النظام (System Boundary):
   - تسجيل منتج جديد (Register Product)
   - إنشاء شحنة (Create Shipment)
   - تحديث درجة الحرارة (Update Temperature)
   - تقييم حالة التخزين تلقائياً (Audit Storage Conditions)
4. اربط "الموظف" بـ (تسجيل منتج، إنشاء شحنة، تحديث حرارة).
5. اربط "النظام التلقائي" بـ (تقييم حالة التخزين) والذي يحدث بناءً على (تحديث الحرارة) بعلاقة <<include>>.

## 3. التصميم المعماري - مخطط تسلسلي (Sequence Diagram)
كيفية رسمه في draw.io:
هذا المخطط يمثل الطبقات الأربع (Client, API Router, Service, Database).
قم بإنشاء 4 أعمدة (Lifelines):
1. Client (Swagger UI / متصفح)
2. API Router (routers/shipments.py)
3. Service (LogisticService / InventoryService)
4. Database (SQLite Models)

ترتيب الرسائل:
1. Client -> API Router: طلب PUT /update-temp (تحديث درجة الحرارة)
2. API Router -> Service: استدعاء دالة update_temperature()
3. Service -> Database: طلب جلب بيانات الشحنة والمنتج (Query)
4. Database -> Service: إرجاع البيانات المطلوبة.
5. Service: تقييم الحرارة (إذا كانت أعلى من الحد -> تغيير الحالة لـ DAMAGED).
6. Service -> Database: حفظ التحديثات (db.commit).
7. Database -> Service: تأكيد الحفظ (Success).
8. Service -> API Router: إرجاع حالة الشحنة ونتيجة الفحص.
9. API Router -> Client: استجابة JSON تحتوي على النتيجة النهائية.
